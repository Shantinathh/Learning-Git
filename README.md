# Learning Git

A beginner-friendly Git and GitHub practice project created locally to learn and understand the basic Git workflow, including repository initialization, staging, committing, branch management, remote configuration, and pushing code to GitHub.

## 📁 Project Setup

This project was created on a local system and connected to a GitHub repository.

**GitHub Repository:**
https://github.com/Shantinathh/Learning-Git

## 🛠️ Git Commands Used

### 1. Navigate to the Project

```bash
cd project2/
```

### 2. Check Project Files

```bash
ls
ls -la
```

### 3. Check Git Status

```bash
git status
```

### 4. Stage Project Files

```bash
git add .
```

### 5. Create the First Commit

```bash
git commit -m "First commit"
```

### 6. Configure the Remote Repository

```bash
git remote add origin https://github.com/Shantinathh/Learning-Git.git
```

### 7. Verify the Remote

```bash
git remote -v
```

### 8. Check the Current Branch

```bash
git branch
```

### 9. Rename the Branch

The branch was renamed to `master` and then changed back to `main` while practicing branch management:

```bash
git branch -M master
git branch

git branch -M main
git branch
```

### 10. Push the Project to GitHub

```bash
git push origin main
```

## 📚 Concepts Practiced

* Navigating directories using the terminal
* Checking files and hidden files
* Initial Git status
* Staging files with `git add`
* Creating commits
* Configuring a remote repository
* Checking remote URLs
* Managing Git branches
* Renaming branches
* Pushing local commits to GitHub

## 🎯 Purpose

The purpose of this project is to gain hands-on experience with **Git and GitHub** and understand the basic workflow used for version control and collaborative software development.
